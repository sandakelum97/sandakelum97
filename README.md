# 💫 About Me:
Senior Security & System Engineer with 8+ years in cybersecurity, enterprise infrastructure, and network security. Currently operating as a Security Engineer at an Australian MSSP (Subnet), delivering threat detection and endpoint defence across a portfolio of ~50 managed enterprise tenants.<br><br>Expertise spans EDR/XDR (CrowdStrike, SentinelOne), SIEM (Microsoft Sentinel, KQL), firewalls (FortiGate, SonicWall), Zero Trust architecture, vulnerability management (Nessus TVM), and identity security (Microsoft Entra ID, Conditional Access).<br><br>Strong hands-on background with Windows Server, Active Directory, VMware ESXi, Microsoft Dynamics NAV/BC, and hybrid backup & disaster recovery. Skilled in networking (Cisco, Meraki, Ruckus) and infrastructure automation (Terraform, Ansible). Pursuing an Executive MSc in Information Security.
